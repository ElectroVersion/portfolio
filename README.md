## 📌 About This Project

This is my personal developer portfolio built as a **single-page static website** hosted on GitHub Pages. It showcases my professional background, technical skills, key projects, and certifications — all in a clean, dark-themed embedded/tech aesthetic.

The site is intentionally **zero-dependency** — no frameworks, no build tools, no npm. Just pure HTML, CSS, and vanilla JavaScript, designed to load fast and work everywhere.

---

## ✨ Features

- 🎨 **Dark theme** with a custom teal (`#00c896`) accent palette
- 🖋️ **Monospace + sans-serif** typography pairing (`Space Mono` + `DM Sans`)
- 📐 Subtle **grid overlay** and **noise texture** background for a hardware/PCB aesthetic
- 📜 **Smooth scroll** navigation with a glassmorphism fixed navbar
- 🎞️ **Scroll-reveal animations** via `IntersectionObserver` (no libraries)
- ⚡ **Glitch effect** on hero heading using pure CSS
- 📊 Stats, project cards, skill tags, certifications, and a hire/contact CTA section
- 📱 **Responsive layout** — works on desktop, tablet, and mobile
- ⚡ **Zero dependencies** — no npm, no build step, no frameworks

## 🚀 Run Locally

No installation or build step needed:

```bash
git clone https://github.com/ElectroVersion/portfolio.git
cd portfolio
```

Then simply open `index.html` in your browser:

```bash
# macOS
open index.html

# Linux
xdg-open index.html

# Windows
start index.html
```

Or use VS Code's **Live Server** extension for hot-reload during development.

---

## 📦 Deploy Your Own Copy

1. **Fork** this repository
2. Go to your repo → **Settings → Pages**
3. Set source to `main` branch, root `/`
4. Your site will be live at `https://<your-username>.github.io/portfolio/`
